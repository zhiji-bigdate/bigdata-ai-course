四节课总览

第 1 课 ──► 地基：认识 Python + 变量 + 基础运算 │ ▼ 第 2 课 ──► 逻辑：条件判断 + 循环 + 列表 │ ▼ 第 3 课 ──► 实战：文件读写 + 处理真实新闻数据 │ ▼ 第 4 课 ──► 产出：数据可视化 + 一个小项目收尾

第 1 课：地基 —— 和 Python 打个照面

学习目标

  • 能用 Python 做基本计算，理解「变量」是什么
  • 能写出第一行 print() 代码
  • 知道 int / float / str 三种数据类型

时间分配

时间内容要点
0–5 分钟认识 Python为什么学、能做什么（结合新闻场景）
5–15 分钟环境准备打开 IDLE 或 VS Code，运行第一行 print("你好")
15–30 分钟变量与运算变量 = 值、加减乘除、字符串拼接
30–40 分钟数据类型数字（int/float）、文字（str）、真假（bool）
40–45 分钟小结 + 练习三道小练习，巩固概念

核心知识点

  • print() 输出
  • 变量命名（标题 = "新闻"）
  • 四则运算、取余 %、整除 //
  • 字符串用引号包裹，+ 可拼接
  • type() 查看类型

练一练（新闻场景）

  1. 打印一句话自我介绍
  2. 计算：一篇 800 字的稿子，平均每段 100 字，共几段？
  3. 把「今日热点」和「：台风来袭」拼成完整标题

第 2 课：逻辑 —— 让程序会「判断」和「重复」

学习目标

  • 能写 if / elif / else 让程序做判断
  • 能写 for 循环批量处理数据
  • 掌握列表（list）这个「万能容器」

时间分配

时间内容要点
0–5 分钟回顾第 1 课快速复习变量和类型
5–20 分钟条件判断if 语句，比较运算符（> < ==）
20–35 分钟for 循环遍历列表、range() 计数
35–43 分钟列表增删查改：append [索引] len
43–45 分钟小结 + 练习用「新闻分类」场景做练习

核心知识点

  • 比较运算符：== != > < >= <=
  • if / elif / else 结构
  • for 变量 in 列表: 循环
  • range(n) 生成数字序列
  • 列表的 append() 和索引访问

练一练（新闻场景）

  1. 写程序：给一篇稿子的字数打分（少于 300 是「短讯」，300–800 是「消息」，大于 800 是「特稿」）
  2. 用一个列表存 5 个新闻标题，用循环逐个打印
  3. 统计列表里有多少条标题包含「台风」

第 3 课：实战 —— 读写文件 + 处理真实数据

学习目标

  • 能读取和写入 .txt 文本文件
  • 能处理 CSV 数据（新闻数据常见格式）
  • 学会「字符串处理」清洗文本

时间分配

时间内容要点
0–5 分钟回顾第 2 课快速复习判断和循环
5–20 分钟文件读写open() read() write()，记得 close()
20–35 分钟字符串处理split replace lower strip，正则入门
35–43 分钟CSV 处理用内置 csv 模块读取数据
43–45 分钟小结 + 练习用真实数据练手

核心知识点

  • open("文件", "r", encoding="utf-8") 读文件
  • with open(...) as f: 优雅写法（自动关闭）
  • 字符串方法：split() strip() replace() count()
  • csv 模块读取表格数据
  • 编码问题：中文记得 encoding="utf-8"

练一练（新闻场景）

  1. 读取一段新闻文字稿，统计总字数和段落数
  2. 把文字里所有的「的」替换成「的✅」检查使用频率
  3. 读取一个 CSV（如新闻标题列表），打印前 10 条

第 4 课：产出 —— 可视化 + 收尾项目

学习目标

  • 能用 matplotlib 画出基础图表
  • 能独立完成一个「数据新闻」小项目
  • 知道下一步该学什么

时间分配

时间内容要点
0–5 分钟回顾第 3 课快速复习文件读写
5–25 分钟matplotlib 入门折线图、柱状图、饼图
25–40 分钟综合小项目从数据到图表的完整流程
40–45 分钟总结 + 进阶路线下一步学什么

核心知识点

  • import matplotlib.pyplot as plt
  • plt.plot() 折线图、plt.bar() 柱状图、plt.pie() 饼图
  • plt.title() plt.xlabel() 设置标题和标签
  • plt.show() 显示图表

综合小项目（数据新闻）

项目：统计近一周某新闻网站 5 个栏目的发稿量，画出柱状图。

  1. 用一个列表存栏目名和对应发稿量
  2. 用 plt.bar() 画柱状图
  3. 加上标题「本周各栏目发稿量对比」
  4. 保存成图片，就是一张可以放进报道的数据图

学习路径与时间线总结

建议的学习节奏

阶段建议说明
课前花 10 分钟看上一课笔记温故知新，衔接更顺
课中跟着敲代码，别只看动手是学编程唯一捷径
课后完成 3 道练习 + 记笔记巩固当天知识点
四课结束后做 1 个自己的小项目把知识串起来

进阶路线（学完四课后）

📊 数据新闻

学 pandas（数据分析）→ 处理大型数据集、做数据调查报道

🕷️ 爬虫

学 requests + BeautifulSoup → 批量抓取新闻、监测舆情

⚙️ 自动化

学脚本 + 定时任务 → 自动整理稿子、自动生成日报

📈 可视化进阶

学 plotly / pyecharts → 交互式图表、数据大屏

🧠 自然语言处理

学 jieba 分词 → 词频分析、情感分析、自动摘要

给新闻学学生的三条建议

  1. 别追求「学完」，追求「会用」——四节课的目标不是背语法，而是能独立跑通一个「数据 → 图表」的小项目。
  2. 把 Python 当「工具」而非「学科」——你不需要成为程序员，只需要让 Python 帮你做重复劳动。
  3. 多拿新闻素材练手——用你真实的采访数据、稿子、问卷来练习，比课本例题记得牢十倍。
