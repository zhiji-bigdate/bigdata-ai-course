贯穿项目：新闻评论情感分析

第1次课 第2次课 第3次课 第4次课 语法地基 → 批量处理数据 → 词频统计 → 情感自动分类 (会写代码) (读入CSV) (jieba+词频表) (sklearn分类器)

学完你能独立回答：「1000 条新闻评论里，读者对这件事整体是支持还是反对？」——这正是数据新闻和舆情分析最常用的一步。

第 1 次课 · 语法入门

上半场｜变量 · 类型 · 字符串（第一段能跑的代码）

  • 知识点：print()、变量、int / float / str、字符串拼接
  • 新闻落点：把「今日热点」和「：台风来袭」拼成完整标题
  • 产出：第一段能运行的 Python 代码

下半场｜列表 · 循环 · 判断（把一段新闻文本拆开）

  • 知识点：if / elif / else、for 循环、列表、比较运算符
  • 新闻落点：给稿子字数打分（<300 短讯 / 300–800 消息 / >800 特稿）
  • 产出：一个会判断、会重复的小程序

第 2 次课 · 语法进阶

上半场｜字典 · 集合 · 推导式（从一条评论到一堆评论）

  • 知识点：字典存键值对、集合去重、列表推导式
  • 新闻落点：用字典记录每条评论的点赞数，按栏目去重
  • 产出：能批量处理评论数据的小脚本

下半场｜函数 · 文件 · 模块（读入一份评论 CSV）

  • 知识点：def 定义函数、with open 读写文件、import 模块
  • 新闻落点：读入 100 条新闻评论的 CSV，封装成可复用的读取函数
  • 产出：comments.csv → 内存数据 的读取管道

第 3 次课 · 语法收口

上半场｜pandas · 异常处理（够用即止）

  • 知识点：DataFrame、read_csv、分组统计、try / except
  • 新闻落点：一行代码算出各栏目的平均评论数
  • 产出：一份评论数据的描述统计表

下半场｜jieba 分词 · 词频统计（产出评论词频表）

  • 知识点：jieba.lcut、Counter、停用词过滤
  • 新闻落点：1000 条评论里，读者最关心什么？词频 Top 20
  • 产出：新闻评论词频表（也是第 4 次课的数据基础）

第 4 次课 · AI 应用

上半场｜情感分析原理（机器怎么分辨好评差评）

  • 知识点：什么是机器学习、训练集 / 测试集、文本向量化（词袋模型）
  • 新闻落点：为什么机器能判断一条新闻评论是赞同还是反对
  • 产出：跑通第一个文本分类小实验

下半场｜sklearn 文本分类实战（给新闻评论自动打分）

  • 知识点：CountVectorizer + 朴素贝叶斯、准确率评估、预测新评论
  • 新闻落点：训练一个「新闻评论情感分类器」，对新评论自动输出 正面 / 负面
  • 产出：贯穿项目完工 —— 评论词频表 + 情感自动分类

建议的学习节奏

阶段建议说明
课前花 10 分钟看上一课笔记温故知新，衔接更顺

课后完成 3 道练习 + 记笔记巩固当天知识点
