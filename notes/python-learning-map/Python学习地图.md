# Python 学习地图 · 四节课速成版

> 面向：新闻学专业大二学生
> 总时长：4 节课 × 45 分钟 = 180 分钟
> 目标：用最短时间建立「能读懂 + 能上手 + 能落地到新闻工作」的 Python 能力

---

## 为什么新闻学学生要学 Python？

| 场景 | 传统做法 | 用 Python 后 |
|------|---------|-------------|
| 整理 1000 条问卷数据 | 手动复制粘贴，几小时 | 一段代码，几秒钟 |
| 统计某关键词出现频率 | 用眼睛数，容易错 | `Counter` 一行搞定 |
| 从网页批量抓取新闻标题 | 一条条复制 | 爬虫自动抓 |
| 给数据做可视化图表 | Excel 手工调 | `matplotlib` 直接出图 |
| 处理采访录音转的文字稿 | 手动整理 | 字符串处理自动清洗 |

**一句话**：Python 是新闻人的「效率外挂」，尤其适合**数据新闻、舆情分析、内容生产自动化**这三个方向。

## 第 1 课：地基 —— 和 Python 打个照面（45 分钟）

### 学习目标
- 能用 Python 做基本计算，理解「变量」是什么
- 能写出第一行 `print()` 代码
- 知道 `int / float / str` 三种数据类型

### 时间分配

| 时间 | 内容 | 要点 |
|------|------|------|
| 0–5 分钟 | 认识 Python | 为什么学、能做什么（结合新闻场景） |
| 5–15 分钟 | 环境准备 | 打开 IDLE 或 VS Code，运行第一行 `print("你好")` |
| 15–30 分钟 | 变量与运算 | `变量 = 值`、加减乘除、字符串拼接 |
| 30–40 分钟 | 数据类型 | 数字（int/float）、文字（str）、真假（bool） |
| 40–45 分钟 | 小结 + 练习 | 三道小练习，巩固概念 |

### 核心知识点
- `print()` 输出
- 变量命名（`标题 = "新闻"`）
- 四则运算、取余 `%`、整除 `//`
- 字符串用引号包裹，`+` 可拼接
- `type()` 查看类型

### 练一练（新闻场景）
1. 打印一句话自我介绍
2. 计算：一篇 800 字的稿子，平均每段 100 字，共几段？
3. 把「今日热点」和「：台风来袭」拼成完整标题

---

## 第 2 课：逻辑 —— 让程序会「判断」和「重复」（45 分钟）

### 学习目标
- 能写 `if / elif / else` 让程序做判断
- 能写 `for` 循环批量处理数据
- 掌握列表（list）这个「万能容器」

### 时间分配

| 时间 | 内容 | 要点 |
|------|------|------|
| 0–5 分钟 | 回顾第 1 课 | 快速复习变量和类型 |
| 5–20 分钟 | 条件判断 | `if` 语句，比较运算符（`>` `<` `==`） |
| 20–35 分钟 | for 循环 | 遍历列表、`range()` 计数 |
| 35–43 分钟 | 列表 | 增删查改：`append` `[索引]` `len` |
| 43–45 分钟 | 小结 + 练习 | 用「新闻分类」场景做练习 |

### 核心知识点
- 比较运算符：`==` `!=` `>` `<` `>=` `<=`
- `if / elif / else` 结构
- `for 变量 in 列表:` 循环
- `range(n)` 生成数字序列
- 列表的 `append()` 和索引访问

### 练一练（新闻场景）
1. 写程序：给一篇稿子的字数打分（少于 300 是「短讯」，300–800 是「消息」，大于 800 是「特稿」）
2. 用一个列表存 5 个新闻标题，用循环逐个打印
3. 统计列表里有多少条标题包含「台风」

---

## 第 3 课：实战 —— 读写文件 + 处理真实数据（45 分钟）

### 学习目标
- 能读取和写入 `.txt` 文本文件
- 能处理 CSV 数据（新闻数据常见格式）
- 学会「字符串处理」清洗文本

### 时间分配

| 时间 | 内容 | 要点 |
|------|------|------|
| 0–5 分钟 | 回顾第 2 课 | 快速复习判断和循环 |
| 5–20 分钟 | 文件读写 | `open()` `read()` `write()`，记得 `close()` |
| 20–35 分钟 | 字符串处理 | `split` `replace` `lower` `strip`，正则入门 |
| 35–43 分钟 | CSV 处理 | 用内置 `csv` 模块读取数据 |
| 43–45 分钟 | 小结 + 练习 | 用真实数据练手 |

### 核心知识点
- `open("文件", "r", encoding="utf-8")` 读文件
- `with open(...) as f:` 优雅写法（自动关闭）
- 字符串方法：`split()` `strip()` `replace()` `count()`
- `csv` 模块读取表格数据
- 编码问题：中文记得 `encoding="utf-8"`

### 练一练（新闻场景）
1. 读取一段新闻文字稿，统计总字数和段落数
2. 把文字里所有的「的」替换成「的✅」检查使用频率
3. 读取一个 CSV（如新闻标题列表），打印前 10 条

## 第 4 课：产出 —— 可视化 + 收尾项目（45 分钟）

### 学习目标
- 能用 `matplotlib` 画出基础图表
- 能独立完成一个「数据新闻」小项目
- 知道下一步该学什么

### 时间分配

| 时间 | 内容 | 要点 |
|------|------|------|
| 0–5 分钟 | 回顾第 3 课 | 快速复习文件读写 |
| 5–25 分钟 | matplotlib 入门 | 折线图、柱状图、饼图 |
| 25–40 分钟 | 综合小项目 | 从数据到图表的完整流程 |
| 40–45 分钟 | 总结 + 进阶路线 | 下一步学什么 |

### 核心知识点
- `import matplotlib.pyplot as plt`
- `plt.plot()` 折线图、`plt.bar()` 柱状图、`plt.pie()` 饼图
- `plt.title()` `plt.xlabel()` 设置标题和标签
- `plt.show()` 显示图表

### 综合小项目（数据新闻）
**项目**：统计近一周某新闻网站 5 个栏目的发稿量，画出柱状图。

流程：
1. 用一个列表存栏目名和对应发稿量
2. 用 `plt.bar()` 画柱状图
3. 加上标题「本周各栏目发稿量对比」
4. 保存成图片，就是一张可以放进报道的数据图

## 进阶路线（学完四课后）

学完这四课，你已经有「Python 入门 + 数据新闻基础」的能力。接下来可以按兴趣深入：

| 方向 | 学什么 | 新闻应用 |
|------|--------|---------|
| **数据新闻** | pandas（数据分析） | 处理大型数据集、做数据调查报道 |
| **爬虫** | requests + BeautifulSoup | 批量抓取新闻、监测舆情 |
| **自动化** | 脚本 + 定时任务 | 自动整理稿子、自动生成日报 |
| **可视化进阶** | plotly / pyecharts | 交互式图表、数据大屏 |
| **自然语言处理** | jieba 分词 | 词频分析、情感分析、自动摘要 |

---

## 给新闻学学生的三条建议

1. **别追求「学完」，追求「会用」**——四节课的目标不是背语法，而是能独立跑通一个「数据 → 图表」的小项目。
2. **把 Python 当「工具」而非「学科」**——你不需要成为程序员，只需要让 Python 帮你做重复劳动。
3. **多拿新闻素材练手**——用你真实的采访数据、稿子、问卷来练习，比课本例题记得牢十倍。
