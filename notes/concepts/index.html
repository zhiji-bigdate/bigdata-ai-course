概念总目录

板块 A · 和 AI 打交道的方式（先学，建立全局观）

上下文 Context
llm-context
大模型每轮"能看到的信息"，是所有概念的地基。
提示词 Prompt
prompt
你"怎么跟大模型说话"，决定答得好不好。
上下文窗口可视化
context-window-visualization
把"上下文塞了多少、还剩多少"画出来看。
智能体 Agent
agent
能自己拿上下文、调工具、按步骤干活的程序。
技能 Skill
skill
把"怎么干某类活"沉淀成可复用的说明书。

板块 B · 大模型的"大脑"原理（搞懂它为什么聪明）

神经网络 / 深度学习
neural-network
大模型的"大脑"，靠层层神经元学会规律。
Embedding（词向量）
embedding
把文字变成数字，机器才"看得懂"语义。
Transformer
transformer
现代大模型的底层骨架（注意力机制）。
微调 Fine-tuning
fine-tuning
用你的数据把通用模型调成"懂行"的。

板块 C · 应用与落地（把前面的串起来用）

RAG（检索增强生成）
rag
让大模型"先查资料再回答"，减少瞎编。
大数据基础
big-data
数据怎么存、怎么算（Hadoop / Spark）。
情感分析
sentiment-analysis
判断文字是正面还是负面（新闻场景落地）。
