🐍 Prompt（提示词）

面向 AI 小白 · 单个概念学习包 · 关联：上下文 / Agent / Skill

1. 学习目标

学完本概念，你能：

  • 理解 Prompt 是什么、在大模型工作流程里的位置
  • 能区分 Prompt 与「问题」「指令」之间的细微差别
  • 能举例 说明一条好的 Prompt 和一条差的 Prompt 差在哪
  • 能用自己的话解释 为什么「把话说清楚」能让大模型答得更好
  • 能识别常见误区 例如「Prompt 越长越好」「加一句请认真回答就能变强」

2. 核心问题

  1. 大模型真的能「听懂」你打的字吗？它到底收到了什么？
  2. 为什么同样问一个东西，换个说法答案质量天差地别？
  3. Prompt 和「上下文（Context）」是什么关系？
  4. 「角色设定」（比如"你是一位资深记者"）为什么有效？
  5. 为什么说 Prompt 不是魔法咒语，而是沟通方式？

3. 概念地图

   │  输入一段文字
   ▼
Prompt（提示词）
   │  被组装进更大的「上下文」
   ▼

   │                                  │

  • Prompt 是输入，不是模型本身
  • Prompt 是上下文的一部分（通常是最新、最"新鲜"的那部分）
  • 一条 Prompt 的质量，直接决定回答的起点高低

4. 结构化解释

4.1 一句话定义

Prompt 是你发给大模型的一段文字指令，用来告诉它"你想要什么、按什么标准、用什么格式回答"。

4.2 直观类比

把大模型想象成一位刚入职、能力很强但完全不了解你的新同事。

  • 你跟他说"帮我弄一下那个报告"，他一脸懵，只能猜——这就是模糊的 Prompt。
  • 你跟他说"帮我整理这份采访录音，把里面提到的三个数据点摘出来，用表格列成三行，第一列是数据、第二列是出处、第三列是原话"——他马上就能干，这就是清晰的 Prompt。

同事能力没变，变的是你交代任务的清晰程度。Prompt 工程，本质就是学会"怎么把话说清楚"。

4.3 机制原理

大模型不是"读心者"，它读的是"文字序列的概率"。你输入的每一个字，都会被拆成 token（词元），送进模型里参与一次"预测下一个词"的计算。Prompt 的作用，就是给这次预测一个明确的方向。

一条好的 Prompt 通常靠这几个要素起作用：

  • 角色（Role）——"你是一位资深财经记者"，会让模型更倾向专业、克制的表达。这不是"赋予身份"，而是改变了它采样的概率分布。
  • 任务（Task）——明确要"做什么"，把"帮我看看"变成"总结成三点"。
  • 上下文/背景（Context）——把模型不知道的信息喂进去。
  • 约束与格式（Constraints & Format）——"用 100 字以内""输出成 JSON""分三段"。
  • 示例（Few-shot）——给一两个"输入→输出"示范，模型照着这个模式继续。

这些要素不是越多越好，而是越贴合当前任务越好。

4.4 边界与误区

  • 误区 1：「Prompt 越长越好」。冗余信息会稀释重点，还可能触发"中间信息被忽略"。精准比冗长重要。
  • 误区 2：「加一句'请认真回答/你是专家'就能变强」。空话对概率分布影响很弱，远不如给具体的角色+任务+格式有效。
  • 误区 3：「Prompt 是一次性的」。好 Prompt 可以沉淀成模板、封装成 Skill 反复复用。
  • 误区 4：「Prompt 就是代码」。它不是编程语言，靠的是自然语言表达的清晰度。

5. 应用案例

案例 A：真实场景——系统提示词

ChatGPT、Claude、WorkBuddy 背后都有一条系统提示词（System Prompt），规定 AI 的身份、行为边界、输出风格。这就是 Prompt 在真实产品里最硬核的应用——它决定了 AI 的"人设"。

案例 B：课堂练习——亲手对比两种问法

  1. 先问模糊版："写点关于台风的。"
  2. 再问清晰版："你是一位地方都市报记者，请写一条 80 字以内的短消息，报道台风'海葵'今晚登陆，需包含登陆时间、地点、预计风力，语气客观，不要标题党。"

对比两次输出——这个差距，就是 Prompt 的价值。

6. 概念辨析

  • Prompt vs 上下文（Context）：Prompt 是你这一次输入的指令；上下文是模型这轮"能看到的一切"的合集，Prompt 只是其中最新的一部分。
  • Prompt vs 问题（Question）：问题只是 Prompt 的一种形态；Prompt 还可以是命令、带格式要求的任务说明、带示例的模板。
  • Prompt vs Skill：Prompt 是一次性输入；Skill 是"把一类好 Prompt 沉淀成可复用的工作说明书"——好 Prompt 被固定下来、长期维护，就成了 Skill。

7. 自测问题

Q1：为什么「你是一位资深记者」会让模型写得更像新闻稿？它真的"变成"记者了吗？

提示：它没有变成记者，而是这句话改变了模型对不同措辞的"偏好概率"。本质是概率分布被引导，不是身份被赋予。

Q2：一条 Prompt 通常包含哪几个关键要素？至少说出三个。

提示：角色、任务、背景/上下文、约束与格式、示例（Few-shot）——任选三个。

Q3：为什么「加一句"请认真回答"」效果很弱？

提示：因为它是没有具体指向的"空话"，对概率分布的影响远不如"给出具体角色+任务+格式"。

7.5 选择题练习

点击展开 5 道选择题（先自己做，再看答案）

第 1 题：以下哪一项最能描述 Prompt 的本质？

  • A. 一种严格的编程语言
  • B. 一段用来引导大模型输出方向的自然语言指令
  • C. 大模型内部的一个模块
  • D. 只有 ChatGPT 才有的功能

A 错：靠自然语言，无严格语法。B 对：本质就是"引导输出的文字指令"。C 错：是输入不是零件。D 错：几乎所有大模型都吃 Prompt。

考点：Prompt 的定位——外部输入，不是模型的一部分。
你如果选了 C：把它当成了模型"身体里的器官"，其实它是你递给模型的"纸条"。

第 2 题：哪条 Prompt 最可能得到"直接能用的新闻短消息"？

  • A. "写点关于台风的。"
  • B. "你是一位都市报记者，请写一条 80 字以内的短消息，报道台风今晚登陆，含时间、地点、风力，语气客观。"
  • C. "请认真、仔细、专业地回答我关于台风的问题。"
  • D. "台风。"

A 错：太模糊。B 对：要素齐全。C 错：形容词是空话。D 错：信息严重不足。

考点：好 Prompt = 具体要素齐全，而不是堆形容词。
你如果选了 C：被"礼貌用语"迷惑了——真诚的形容词不等于清晰的指令。

第 3 题：Prompt 和"上下文（Context）"是什么关系？

  • A. 完全是一回事
  • B. Prompt 是上下文的一部分（通常是最新输入）
  • C. 上下文是 Prompt 的一部分
  • D. 两者毫无关系

A 错。B 对：上下文 = system prompt + 历史 + 工具返回 + 当前 Prompt 的合集。C 错：方向反了。D 错。

考点：部分与整体的关系。
你如果选了 C：把包含关系记反了，记住"上下文是更大的那个筐"。

第 4 题：把好 Prompt 沉淀成长期可复用的模板，更接近哪个概念？

  • A. Skill
  • B. 变量
  • C. 缓存
  • D. 报错

A 对：Skill 正是把最佳 Prompt/流程固定下来反复用。B 错。C 错：缓存是临时存结果，不是存方法。D 错。

考点：Prompt（一次性）→ Skill（长期复用）的演进。
你如果选了 C：缓存是"临时存结果"，Skill 是"存方法"，别混淆。

第 5 题：关于 Prompt 的说法，哪一项是"误区"？

  • A. Prompt 越长一定越好
  • B. 好的 Prompt 要贴合具体任务
  • C. 给一两个示例（Few-shot）常常很有效
  • D. Prompt 是自然语言，不是代码

A 是误区（选它）：冗余会稀释重点。B/C/D 都是正确认知。

考点：识别"越长越好"这个最普遍的误区。
你如果选了 B/C/D：已经理解正确做法，只是没注意题目问的是"误区"。
