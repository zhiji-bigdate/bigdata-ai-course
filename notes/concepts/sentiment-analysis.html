4. 结构化解释

4.1 一句话定义

情感分析是让计算机自动判断一段文字（比如一条评论）表达的是正面还是负面情绪，有时还能细分出愤怒、喜悦、悲伤等具体情绪。

4.2 直观类比

想象你是新闻编辑部里专门看读者来信的实习生。

  • 主编交给你一堆读者评论，让你按"夸我们"还是"骂我们"分成两摞。
  • 评论少还行，一天来几万条你根本读不完。于是你总结出一套判断标准——看到"太棒了""点赞""感动"往"夸"那摞，看到"失望""胡扯""垃圾"往"骂"那摞。

情感分析就是把这个过程自动化：让计算机学会你那套"判断标准"，然后一秒处理几万条评论，自动归到"正面"或"负面"，还能统计出"这条新闻下 70% 好评、30% 差评"。

4.3 机制原理

最朴素的做法是"词典法"。准备一份情感词典，标好哪些词正面（"优秀""温暖""给力"）、哪些负面（"糟糕""愤怒""失望"），再看一句话里正面词多还是负面词多，简单投票。它简单、快、可解释，但有致命短板：不懂语境。"这电影一点都不烂"里有"烂"，词典法可能误判成负面；"真是好极了"这种反讽，它也完全看不出来。

现代主流做法是"机器学习法"——把情感分析当成分类任务。你需要一批已标注数据：成千上万条评论，每条有人工标好的"正面/负面"标签。然后训练一个分类器（通常是神经网络）去学"什么样的文字 → 什么情感"。

具体流程分三步。第一步文本预处理：分词、去掉无意义符号。第二步表示（Embedding）：把每条评论变成向量，让"意思相近的话，向量也相近"（正是你在 embedding 里学到的）。第三步分类：让神经网络（或微调后的预训练模型）读这个向量，输出"正面""负面"各自的概率，取高的那个作为结果。

为什么现在准确率高了很多？因为人们越来越多地拿预训练语言模型（如 BERT）做情感分析：这些模型已"懂中文"，你只需加一个分类头，再用标注数据微调（Fine-tuning）一下，它就能把"通用语言理解"转化为"判断情感"的能力——还能捕捉语境和部分反讽，效果远超词典法。

它和大数据的关系也很直接。情感分析模型的"聪明"，完全来自训练数据的数量和质量。没有成千上万条标注评论，模型学不会；数据里偏见多，模型也跟着偏。

4.4 边界与误区

  • 误区 1：「情感分析能完全读懂反讽和幽默」。反讽、阴阳怪气、双关，至今仍是难点，模型经常翻车。
  • 误区 2：「只要有本好词典，就能分析得很准」。词典法不懂语境，现代高精度靠机器学习 + 大量标注数据，不是词典。
  • 误区 3：「情感只有"正"和"负"两种」。还有"中性"，以及更细的"愤怒/喜悦/悲伤/恐惧"等多分类。
  • 误区 4：「模型给的分就是绝对客观的真相」。判断受训练数据影响会有偏见，而且"情感"本身也常模糊、多义。

5. 应用案例

案例 A：真实场景——舆情监测与品牌口碑

很多新闻机构、政府部门、企业会用情感分析系统实时扫描全网：抓取某条新闻、某个事件、某款产品下的海量评论，自动判断每条是正面还是负面，再汇总成"舆情曲线"。比如一款手机发布后，系统能快速告诉你"微博上关于它续航的讨论，负面情绪占比突然上升了 20%"，帮你第一时间发现危机。这就是情感分析 + 大数据在真实世界的典型组合。

案例 B：课堂练习——用大模型判断新闻评论的情感（贯穿项目）

这是本课程贯穿项目的核心练习。打开 VS Code，新建 sentiment_demo.py，用你已经会的"提示词"思路，让一个大模型帮你判断新闻评论的情感：

reviews = [
    "这条新闻说得太实在了，终于有人讲真话！",
    "看完只想说，这是什么乱七八糟的报道。",
    "纯属标题党，浪费我时间。",
    "写得很客观，把两边观点都摆出来了。",
]

prompt = (
    "你是新闻评论情感分析助手。请判断下面每条评论的情感，"
    "只输出「正面 / 负面」之一，一行一条：\n" + "\n".join(reviews)
)
print(prompt)

运行后，把这段 prompt 复制到任意大模型对话里，你会看到它逐条给出"正面/负面"。再和你的直觉核对：它有没有把"标题党"判断成负面？有没有把"客观"判断成正面？如果换成"用 0-10 表示情感强度"，输出又会不同——这正呼应了"提示词"和"情感分析"两个概念。

6. 概念辨析

  • 情感分析 vs 文本分类：文本分类是"给文字打标签"的大类（主题分类、垃圾邮件识别）；情感分析是其中专门打"情感标签"的一种。区别在于标签是否与情绪相关。
  • 情感极性 vs 情绪类别：极性是"正/负/中性"的粗粒度；情绪类别是"愤怒/喜悦/悲伤"的细粒度多分类。区别在于颗粒度粗细。
  • 词典法 vs 机器学习法：词典法是"查词投票"，快但不懂语境；机器学习法是"用标注数据训练分类器"，准但需数据和算力。区别在于是否依赖训练数据与模型。

7. 自测问题

Q1：从"一条新闻评论"到"一个情感标签"，中间大致经过哪几步？

提示：文本预处理 → 表示（Embedding 变向量）→ 分类器（神经网络/微调模型）输出正负概率 → 取最高者作为标签。

Q2：为什么"词典法"常常判断不准？举一个它会翻车的例子。

提示：因为它不懂语境。比如"一点都不烂"里有"烂"，词典法可能误判负面；反讽"真是好极了"它也看不出来。

Q3：为什么说情感分析模型"聪不聪明"，很大程度取决于训练数据？

提示：因为它是机器学习出来的，判断能力来自标注数据的数量与质量；数据少、有偏见，模型就学不好、学偏。

7.5 选择题练习

第 1 题：情感分析最本质的任务是什么？

  • A. 自动判断一段文字表达的是正面、负面（或更细的情绪）
  • B. 把文字翻译成英文
  • C. 给文档加密
  • D. 统计一篇文章的字数

A 对：情感分析就是"给文字打情感标签"。B/C/D 错。

考点：情感分析 = 文本分类里"打情感标签"的一种。
你如果选了 B：那是机器翻译，和判断情绪无关。

第 2 题：现代高精度的情感分析，通常靠什么方法？

  • A. 用大量标注数据训练分类器（神经网络 / 微调预训练模型）
  • B. 只靠一本正负面词典投票
  • C. 人工一条条读
  • D. 掷硬币

A 对：机器学习法，能捕捉语境。B 错：词典法不懂语境。C 错：人工太慢。D 错。

考点：词典法 vs 机器学习法的优劣。
你如果选了 B：词典法能用，但"不懂语境"是硬伤，现代方案靠训练。

第 3 题：哪句话，纯词典法最容易判断错？

  • A. "这电影一点都不烂。"
  • B. "这电影太烂了。"
  • C. "这电影真差劲。"
  • D. "这电影烂透了。"

A 最容易错（选它）：里面有"烂"，但整体是"否定+烂"，意思其实是夸。B/C/D 都是明确负面。

考点：词典法不懂"否定"和"语境"。
你如果选了 D：D 是明确负面，词典法不会错；真正难的是带否定词的 A。

第 4 题：关于情感分析的说法，哪一项是误区？

  • A. 情感分析能完全读懂反讽和幽默
  • B. 情感不只有"正/负"，还有"中性"和更细的情绪
  • C. 训练情感分析模型需要大量标注数据
  • D. 新闻舆情监测常用到情感分析

A 是误区（选它）：反讽、双关至今仍是难点，模型经常翻车。B/C/D 都是正确认知。

考点：识别"能读懂反讽"这个误区。
你如果选了 C：C 是对的——模型"聪明"全靠标注数据的数量和质量。
