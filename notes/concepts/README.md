## 二、概念总目录（12 个概念）

### 板块 A：和 AI 打交道的方式（4 个）——先学这些，建立全局观

| 概念 | 文件 | 一句话定位 | 前置概念 |
|------|------|-----------|---------|
| 上下文 Context | `llm-context` | 大模型每轮"能看到的信息"，是所有概念的地基 | 无 |
| 提示词 Prompt | `prompt` | 你"怎么跟大模型说话"，决定答得好不好 | 上下文 |
| 上下文窗口可视化 | `context-window-visualization` | 把"上下文塞了多少、还剩多少"画出来看 | 上下文 |
| 智能体 Agent | `agent` | 能自己拿上下文、调工具、按步骤干活的程序 | 上下文 + Prompt |
| 技能 Skill | `skill` | 把"怎么干某类活"沉淀成可复用的说明书 | Agent + Prompt |

> 注：板块 A 实为 5 个概念（含 Skill），上下文窗口可视化是上下文的延伸理解。

### 板块 B：大模型的"大脑"原理（4 个）——搞懂它为什么聪明

| 概念 | 文件 | 一句话定位 | 前置概念 |
|------|------|-----------|---------|
| 神经网络 / 深度学习 | `neural-network` | 大模型的"大脑"，靠层层神经元学会规律 | 无 |
| Embedding（词向量） | `embedding` | 把文字变成数字，机器才"看得懂"语义 | 神经网络 |
| Transformer | `transformer` | 现代大模型的底层骨架（注意力机制） | Embedding |
| 微调 Fine-tuning | `fine-tuning` | 用你的数据把通用模型调成"懂行"的 | Transformer |

### 板块 C：应用与落地（3 个）——把前面的串起来用

| 概念 | 文件 | 一句话定位 | 前置概念 |
|------|------|-----------|---------|
| RAG（检索增强生成） | `rag` | 让大模型"先查资料再回答"，减少瞎编 | 上下文 + Embedding |
| 大数据基础 | `big-data` | 数据怎么存、怎么算（Hadoop/Spark） | 无 |
| 情感分析 | `sentiment-analysis` | 判断一段文字是正面还是负面（新闻落地） | Embedding + 微调 |

## 三、推荐学习路径

```
起点
 │
 ├─ 路线 1【先建立全局观】──► 上下文 → Prompt → Agent → Skill
 │
 ├─ 路线 2【再懂底层原理】──► 神经网络 → Embedding → Transformer → 微调
 │
 └─ 路线 3【最后落地应用】──► RAG → 情感分析 → 大数据基础
                                    │
                                    ▼
                          回到课程贯穿项目：新闻评论情感分析
```

**给新闻学学生的建议顺序**：先走路线 1（知道 AI 怎么用），再走路线 2 的 Embedding + 情感分析（对应你的贯穿项目），Transformer、神经网络、微调、RAG、大数据可以按兴趣深入。

```

      │
      ▼

      │
      ▼
情感分析 ── 用分类器判断 正面 / 负面
      │
      ▼
（可选）微调 ── 用新闻评论数据把模型调得更准
      │
      ▼
（可选）RAG ── 让模型"查证"后再给结论
```

## 六、如何使用本目录

1. **想系统学**：按「推荐学习路径」从上往下走。
